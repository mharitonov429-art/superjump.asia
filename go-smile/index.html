GO SMILE — трекер улыбок

GO SMILE — трекер (счётчик) улыбок: он помогает отслеживать ежедневные улыбки. Продукт предлагается в ряду продуктов Super Jump.

Открыть GO SMILE

Как это работает

  • Бесплатно. Пользоваться трекером можно бесплатно.
  • По приглашению. Регистрация идёт по приглашению: вы переходите на GO SMILE по ссылке с этой страницы и оказываетесь в команде автора сайта, а он видит вашу регистрацию в своём кабинете Super Jump. Условия и согласия при регистрации показывает сайт GO SMILE — прочитайте их, прежде чем продолжить.
  • Своё лицо или персонаж. Приложение считает улыбки с помощью камеры. На экране можно видеть себя, а можно выбрать персонажа; персонажи открываются по мере накопления улыбок. Перед началом прочитайте в приложении раздел «Не храним фото».
